Privacy policy

Snap 24 — operated by Marcustut · Last updated 30 September 2026

Snap 24 is a puzzle game. It needs nothing from you, and it keeps nothing about you.

What we collect

  • No accounts, no sign-in, no profile. Nothing identifies you to us.
  • No analytics, no cookies, no advertising, no tracking pixels.
  • No third parties. The server loads no external assets and calls no other services, and the game board makes no network requests of its own.

What the server holds

  • A dealt hand (its cards, target and difficulty) lives in the server's memory, keyed by a random puzzle_id, for 30 minutes, and is then discarded. It contains nothing about you.
  • Sending the contents of a hand to the server is the only data transfer the plugin performs, and it is game state you already see on screen.

Server logs

Like any web service, the server keeps ordinary request logs (request path, time and the connecting IP address) via the system's journal, used only to keep the service running and to diagnose faults. They are not used for profiling, and are not shared or sold.

Children

Snap 24 is a arithmetic puzzle suitable for all ages and collects no personal information from anyone, including children.

Your choices

Because nothing personal is stored, there is nothing to delete or export. If you would like a hand forgotten immediately, stop using it — it expires within 30 minutes.

Changes

If this policy changes, the date above changes with it. Material changes will be noted on this page.

Contact

Questions about privacy: support@marcustut.me, or see support.
